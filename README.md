# Studio Script Editor

A browser-based, Studio-inspired Luau script editor. Run it with `npm install` and `npm run dev`.

Scripts are stored in browser local storage. The editor supports multiple scripts, syntax highlighting, basic Luau snippets, find and replace, undo/redo, and editor settings. This is a frontend replica, not Roblox Studio: it cannot execute Luau, access Roblox services, analyze scripts, render a 3D viewport, or publish experiences.
